avoid explicit for loops whenever possible

for example, matrix and vector multiplication

u = Av

where u and v are vectors, and A is a matrix

then 

u(i) += A(i)(j) * v(j)

where i represents rows of the matrix and elements/dimensions in the vector, each row in the matrix is multiplied and added into the corresponding dimension of the vector

in code, this would two nested for loops, cause we would need to loop over i and then loop over j

BUT INSTEAD, we can just use:

u = np.dot(A, v)

and it will take much less time

EXAMPLE:

if we wanted to apply the exponential operation on every element of a matrix(each element in the power of e)

in vanilla python, we would need to raise each element, and would need a for loop

but numpy has a function called exp(), which does this exact thing for us, and it is much faster

other examples: np.log(), np.abs(), np.maximum(v, 0), v**2(raises each element to power 2), 1/v(inverses each element)
